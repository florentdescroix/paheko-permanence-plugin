# Description
Cet outil à pour but de simplifier les tenue de permanences en proposant une interface basique reliée à Paheko.
Actuellement développé pour une association bien spécifique, il est en cours de généralisation.

# Instalation
Copiez-coller le contenu du repos dans le dossier data/plugins/perm de votre instalation Paheko

# Infra
Le dévelopement de l'interface utilise le framework Vuetify.
